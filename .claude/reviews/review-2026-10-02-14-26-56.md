## 实现要点

### 文件粘贴上传流程

```
用户粘贴 (Ctrl+V)
    │
    ▼
_handlePaste() ─── 提取 ClipboardEvent 中的 file 项
    │
    ▼
_uploadFiles(files)
    │
    ├── 1. 为每个文件生成 tempId (temp-{timestamp}-{random})
    ├── 2. 为图片文件创建 blob URL，存入 _localPreviews[tempId]
    ├── 3. 创建 FileAttachment (fileid=tempId)，添加到 _pendingFiles
    │       ↑ 此时 UI 立即显示文件缩略图（即时反馈）
    ├── 4. 设置 _uploadStates[tempId] = 'uploading'
    │
    ▼
    并行上传所有文件
    │
    ├── 5. fileStorage.upload() 完成
    ├── 6. 生成 realFileid = "{md5}.{ext}"
    ├── 7. 迁移 blob URL: _localPreviews[tempId] → _localPreviews[realFileid]
    ├── 8. 更新 attachment.fileid = realFileid
    ├── 9. 设置 _uploadStates[realFileid] = 'loaded'
    │
    ▼
用户点击发送
    │
    ▼
_submit()
    │
    ├── 10. contentData.files = _pendingFiles（含真实 fileid）
    ├── 11. 清理所有 blob URLs (URL.revokeObjectURL)
    └── 12. 重置所有文件状态
```

### 关键设计决策

1. **先显示后上传**: 先用临时 ID 创建 FileAttachment 立即渲染，再异步上传，提供即时反馈
2. **blob URL 迁移**: 上传完成后将 key 从 tempId 迁移到 realFileid，避免 UI 闪烁
3. **发送后清理**: 发送消息后统一 revoke 所有 blob URL，防止内存泄漏
4. **组件销毁清理**: disconnectedCallback 中也清理 blob URL
