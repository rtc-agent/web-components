Key Design Decisions:

  • Color tokens are intentionally NOT defined here (they go in themes/light.ts & themes/dark.ts)
  • All variables use --rtc- prefix for namespacing
  • Tokens defined in :host for Shadow DOM compatibility
  • Exported as Lit CSSResult for easy composition into component styles
