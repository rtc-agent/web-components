🧪 Task 09 Debug — <rtc-title-bar> 完整实现

本页面验证内容：

1. <rtc-title-bar> 组件正确渲染（Shadow DOM 隔离）

2. 应用标签（app-label）显示，默认值为 "RTC Agent"

3. 最小化按钮渲染并可点击

4. 最大化/恢复按钮渲染并可点击，图标和 title 根据 window-mode 切换

5. 三个公共事件正确触发：rtc-window-minimize, rtc-window-maximize, rtc-window-restore

6. 样式使用 CSS 变量（设计令牌），支持 Light/Dark 主题

7. 拖拽光标样式（grab / grabbing）

  6. 确认 Demo 2（window-mode="maximized"）的右侧按钮显示 恢复图标，hover 时 title 为 "Restore"
  7. 点击 Demo 2 的恢复按钮，确认事件日志中出现 rtc-window-restore
  8. 确认标题栏鼠标样式为 grab（手型），按下时变为 grabbing
  9. 使用「动态修改」区域修改 app-label 和 window-mode，确认组件实时响应
  10. 切换 Light/Dark 主题，确认标题栏颜色跟随变化
  11. 打开浏览器 DevTools，确认 <rtc-title-bar> 使用了 Shadow DOM
