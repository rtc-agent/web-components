🧪 Task 10 Debug — <rtc-content-wrapper> 布局组合

本页面验证内容：

1. <rtc-content-wrapper> 组件正确渲染（Shadow DOM 隔离）

2. 组件内部包含 5 个子组件：session-header、content-area、notice-bar、input-area、overlay-manager

3. 布局为垂直 flex 布局（column 方向）

4. 事件转发：session-header 的 rtc-session-panel-toggle 事件触发 overlay-manager.openSessionPanel()

5. 事件转发：input-area 的 rtc-mode-panel-toggle 事件触发 overlay-manager.openModePanel()

6. 样式使用 CSS 变量（--rtc-z-content 等），支持 Light/Dark 主题

7. 与 <rtc-title-bar> 组合使用，构成完整窗口布局

📋 人工验证清单

  1. 确认 Demo 1 显示完整窗口布局：顶部标题栏 + 下方内容区
  2. 打开 DevTools，确认 <rtc-content-wrapper> 使用了 Shadow DOM
  3. 在 DevTools 中查看 <rtc-content-wrapper> 的 Shadow Root，确认包含 5 个子组件标签
  4. 确认 5 个子组件按顺序排列：session-header → content-area → notice-bar → input-area → overlay-manager
  5. 确认布局方向为 flex-direction: column（垂直排列）
  6. 点击「触发 session-panel-toggle」按钮，确认事件日志中出现 openSessionPanel() 被调用
  7. 点击「触发 mode-panel-toggle」按钮，确认事件日志中出现 openModePanel() 被调用
  8. 切换 Light/Dark 主题，确认整个窗口颜色跟随变化
  9. 确认内容区高度占满剩余空间（flex: 1）
  10. 确认 <rtc-content-wrapper> 的 z-index 使用 CSS 变量 --rtc-z-content
