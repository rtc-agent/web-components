🧪 Task 11 Debug - 空状态与通知栏组件

任务目标：实现两个纯展示组件

  • <rtc-empty-state> - 无消息时显示的空状态组件（居中 logo + 提示文本）
  • <rtc-notice-bar> - 可关闭的通知栏组件（显示在内容区和输入区之间）

📋 人工验证清单

  1. 空状态组件 - Shadow DOM：检查 <rtc-empty-state> 是否正确渲染了 Shadow DOM
  2. 空状态组件 - 默认提示文本：验证默认显示 "/model" 相关的提示文本
  3. 空状态组件 - 自定义提示文本：通过 hint-text 属性设置自定义文本，验证是否正确显示
  4. 空状态组件 - Logo 区域：检查是否渲染了 logo 容器和 SVG 图标
  5. 通知栏组件 - 有消息时渲染：设置 message 属性后，验证通知栏是否正确显示
  6. 通知栏组件 - 无消息时不渲染：不设置 message 属性时，验证通知栏不显示
  7. 通知栏组件 - 关闭按钮：检查是否有关闭按钮（×）
  8. 通知栏组件 - 关闭功能：点击关闭按钮后，验证通知栏是否隐藏
  9. 通知栏组件 - 事件触发：点击关闭按钮后，验证是否触发了 rtc-notice-dismissed 事件
  10. 样式验证：检查组件是否使用了 CSS 变量，样式是否符合设计规范
