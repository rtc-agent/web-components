🧪 Task 13 Debug - 消息组件（Markdown 渲染）

任务目标：实现 <rtc-message> 组件，渲染单条 AI 消息，含时间线圆点 + Markdown 内容。

核心功能：

  • 时间线圆点（可点击，hover 放大 2x + 阴影）
  • Markdown 渲染（使用 marked + dompurify，懒加载）
  • 支持 thinking 状态（灰色斜体 "Thinking ›"）
  • 支持 streaming 状态（中间态）
  • 支持 success 状态（最后一条消息完成时，圆点变绿）
  • 代码块、行内代码、加粗、列表等 Markdown 元素正确渲染
