Task 15 - 内容区域切换

验证 <rtc-content-area> 组件根据消息列表状态在空状态（<rtc-empty-state>） 和消息列表（<rtc-message-list>）之间切换的功能。

场景 1：初始空状态 → 添加消息 → 清空

当前状态： 空状态

消息数量：0

✅ 验证清单

  • 初始状态：显示空状态视图（logo + 提示文字 "Type /model to pick the right tool for the job."）
  • 添加消息后：空状态消失，消息列表出现，显示消息内容
  • 清空消息后：消息列表消失，恢复空状态视图
  • 切换过程平滑，无闪烁或残留元素

场景 2：初始有消息 → 验证消息列表渲染

当前状态： 消息列表（预置 2 条消息）

✅ 验证清单

  • 初始加载即显示消息列表（非空状态）
  • 消息渲染正确：用户消息（右侧蓝色）和助手消息（左侧白色）
  • 消息内容中的 Markdown 正确渲染（粗体、代码块）
  • 列表布局正常，无溢出或错位

通用验证

✅ 组件结构验证

  • <rtc-content-area> 使用 Shadow DOM（在 DevTools 中检查 shadow root）
  • Shadow DOM 内包含 <div class="content-container">
  • 空状态时 shadow DOM 内有 <rtc-empty-state>，无 <rtc-message-list>
  • 有消息时 shadow DOM 内有 <rtc-message-list>，无 <rtc-empty-state>
  • 容器布局正确：:host 为 display: flex; flex: 1;
