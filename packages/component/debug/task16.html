Task 16 - 输入区域组件（修正版）

验证 <rtc-input-area> 组件的修正布局：textarea 在上、工具栏在下、 包含发送按钮。对照 Claude Code 截图验证 UI 还原度。

场景 1：布局 & 基本输入提交

当前模式： Manual

事件日志：
暂无事件

✅ 验证清单

  • 布局顺序：textarea 在上方（占主要空间），工具栏在下方（紧贴底部）
  • Textarea 右上角：语音输入按钮（麦克风图标），点击触发 rtc-voice-input-requested 事件
  • 工具栏左侧：附件按钮（回形针图标）+ 工具按钮（扳手图标）
  • 工具栏右侧：模式按钮（显示当前模式）+ 发送按钮（↑箭头）
  • 发送按钮：初始为空内容时禁用（灰色/半透明），输入内容后启用
  • 输入内容后按 Enter → 触发 rtc-input-submit 事件，textarea 清空
  • 输入内容后点击 发送按钮 → 同样触发提交事件
  • 按 Shift+Enter → 不提交，文本框中插入换行
  • 文本框为空时按 Enter 或点击发送按钮 → 不触发事件
  • 点击模式按钮 → 触发 rtc-mode-panel-toggle 事件

场景 2：发送按钮状态

✅ 验证清单

  • 初始状态：发送按钮为禁用态（灰色/透明度低，不可点击）
  • 在 textarea 中输入任意字符后：发送按钮变为启用态（颜色正常）
  • 清空 textarea 后：发送按钮恢复禁用态
  • 提交后 textarea 清空，发送按钮恢复禁用态

场景 4：Shadow DOM 结构验证

✅ 组件结构验证（在 DevTools 中检查）

  • <rtc-input-area> 使用 Shadow DOM（有 shadow root）
  • :host 有 margin、border-radius、box-shadow，呈现悬浮卡片效果
  • Shadow DOM 内有 <div class="input-inner">（flex column 容器）
  • .input-inner 内有 .textarea-container（含 textarea + voice-btn）和 .input-toolbar
  • Textarea 右上角有语音按钮，工具栏右侧有模式按钮 + 发送按钮
  • 按钮有 part 属性：part="textarea"、part="voice-btn"、part="toolbar"、part="mode-btn"、part="send-btn"
  • 所有样式通过 CSS 变量（--rtc-*）驱动，无硬编码颜色
