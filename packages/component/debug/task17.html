Task 17 - 浮层组件（修正版）

验证 <rtc-overlay-manager>、<rtc-session-panel>、 <rtc-mode-panel>、<rtc-tool-confirm> 四个组件的功能与视觉效果。

场景 1：<rtc-session-panel> 会话列表面板

↑ 面板将出现在此容器顶部
暂无事件

✅ 验证清单

  • 面板使用 Shadow DOM，有悬浮阴影效果
  • 每个会话项显示标题（单行溢出省略号）+ 更新时间（小字灰色）
  • 鼠标悬停会话项 → 背景变灰 + 右侧出现 [编辑] [删除] 两个图标按钮
  • 当前打开的会话项（current-session-id 匹配）→ 背景变灰常驻
  • 点击会话项 → 触发 rtc-session-selected 事件
  • 点击编辑按钮 → 触发 rtc-session-rename-requested
  • 点击删除按钮 → 触发 rtc-session-delete-requested
  • 会话列表为空时显示 "No sessions yet" 居中文字

场景 2：<rtc-mode-panel> 模式选择面板

每个模式应显示图标 + 名称 + 描述，当前模式在右侧显示 ✓，参考 Claude Code 的 Modes 面板。

↓ 面板将出现在此容器底部
暂无事件

✅ 验证清单

  • 每个模式项包含：左侧图标 + 名称（大字号）+ 描述文字（小字灰色）
  • 当前模式项：文字变为主题色、加粗，右侧显示 ✓ 对钩图标
  • 5 个模式：Manual / Edit automatically / Plan / Auto / Bypass permissions
  • 鼠标悬停 → 背景变灰
  • 点击模式项 → 触发 rtc-mode-selected 事件，detail 包含 mode
  • 切换 current-mode 后，✓ 图标立即转移到新模式项右侧

场景 3：<rtc-tool-confirm> 工具确认对话框

对话框应居中出现在此容器内
暂无事件

✅ 验证清单

  • 有半透明背景遮罩 .backdrop，点击遮罩 → 触发 rtc-tool-call-denied（关闭弹窗）
  • 对话框居中显示
  • 工具信息区域：工具名（主题色加粗）+ 参数 JSON（等宽字体）
  • 三个按钮：Yes（蓝色填充）、Yes, allow all（普通）、No（红色文字）
  • 点击 Yes → 触发 rtc-tool-call-approved（detail.allowAll = false）
  • 点击 Yes, allow all → 触发 rtc-tool-call-approved（detail.allowAll = true）
  • 点击 No → 触发 rtc-tool-call-denied

场景 4：<rtc-overlay-manager> 集成管理

集成展示 overlay-manager 管理面板的能力。面板互斥（同时只开一个），按 Esc 关闭。
当前模式：manual   当前会话：s1

Overlay Manager 工作区域
暂无事件

✅ 验证清单

  • 点击 "打开会话面板" → rtc-session-panel 出现，位置由 @floating-ui/dom 自动定位
  • 当前会话项（s1）有常驻灰色背景
  • 点击 "打开模式面板" → 会话面板关闭，模式面板出现（互斥）
  • 按 Esc → 当前面板关闭
  • 点击 "触发工具确认弹窗" → rtc-tool-confirm 出现，带遮罩
  • 在 tool-confirm 上点击 Yes / Yes, allow all / No → 触发对应事件，弹窗关闭
  • 点击 tool-confirm 的 遮罩背景 → 触发 denied 事件，弹窗关闭
  • 点击 "清除待处理工具" → 工具确认弹窗消失
