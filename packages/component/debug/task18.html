Task 18 - <rtc-login-page> 登录页面

验证 <rtc-login-page> 组件：Logo + 应用名 + 登录按钮 + 加载态 + 错误态。 组件通过 @lit/context 消费 AuthContext，点击登录按钮触发 rtc-login-requested 事件。

场景 1：默认状态（Logo + 应用名 + 登录按钮）

默认应用名为 "RTC Agent"，应显示居中的 Logo、应用名、描述文字和登录按钮。

↑ 登录页面应在此容器内居中显示
暂无事件

✅ 验证清单

  • 使用 Shadow DOM 隔离样式
  • 居中显示一个 72×72 的 SVG Logo（主题色，0.7 透明度）
  • Logo 下方显示应用名 "RTC Agent"（大字号加粗）
  • 应用名下方显示描述文字 "Sign in to continue"（小字灰色）
  • 底部显示蓝色 Login 按钮（主色背景 + 反色文字）
  • 鼠标悬停按钮 → 背景色加深（--rtc-color-primary-hover）
  • 点击 Login 按钮 → 触发 rtc-login-requested 事件（bubbles + composed）

场景 2：自定义应用名（app-name 属性）

↑ 应用名应随属性变化实时更新

✅ 验证清单

  • 点击 "设为 智能助手" → 应用名变为 "智能助手"
  • 点击 "设为 My Chatbot" → 应用名变为 "My Chatbot"
  • 点击 "重置为默认" → 应用名恢复为 "RTC Agent"
  • 切换过程中 Logo 和按钮位置保持稳定，无跳动

场景 3：加载状态（loading 属性）

当 loading 属性为 true 时，按钮应消失，显示 "Authorizing..." 文字。

↑ 加载态应替换登录按钮

✅ 验证清单

  • 开启加载 → Login 按钮 消失，显示灰色文字 "Authorizing..."
  • 关闭加载 → "Authorizing..." 消失，Login 按钮 恢复显示
  • 加载态下点击区域不会触发 rtc-login-requested 事件

场景 4：错误状态（error-message 属性）

当设置 error-message 时，应在描述文字下方显示红色错误提示。

↑ 错误信息应显示在按钮上方

✅ 验证清单

  • 点击 "认证失败，请重试" → 按钮上方出现 红色 错误文字
  • 点击 "Token expired" → 错误文字更新为 "Token expired"
  • 点击 "清除错误" → 错误文字消失，Login 按钮正常显示
  • 错误文字颜色为 --rtc-color-error（红色）

场景 5：主题切换（light / dark）

↑ 主题切换后背景与文字颜色应同步变化

✅ 验证清单

  • Light 主题：白色背景 + 深色文字 + 蓝色按钮
  • Dark 主题：深色背景（#1e1e1e）+ 浅色文字 + 亮蓝色按钮
  • 切换主题时过渡平滑，无闪烁
