📝 实现说明

文件结构：

  • src/styles/themes/light.ts — 浅色主题 (20 个颜色变量)
  • src/styles/themes/dark.ts — 深色主题 (20 个颜色变量)
  • src/styles/base.ts — 基础样式 (reset, font, motion)
  • src/styles/index.ts — 导出入口

测试： 12 个新测试全部通过

运行测试： pnpm --filter @rtc-agent/component exec vitest run src/styles/

关键设计决策：

  • 颜色 token 的单一数据源：仅在 light.ts 和 dark.ts 中定义
  • tokens.ts 仅定义结构 token（间距、字体、阴影等）
  • 通过 theme 属性切换主题（:host([theme='dark'])）
  • 基础样式包含 prefers-reduced-motion 媒体查询（可访问性）
  • 所有变量使用 --rtc- 前缀避免命名冲突
